# The Gilded Gallery — a stealth heist game

You are Wren, thief-for-hire. Cross the Meridian Gallery at night, read the
guards' vision cones, dodge the sweeping cameras, lift the Aurora Diamond
from its pedestal, and slip out the service door before the alarm hits 100%.

- **Move:** WASD / arrow keys · **Sneak:** Shift (harder to spot, slower)
- **Q:** smoke bomb — costs $150 of loot, blocks every cone for 4s
- **E:** EMP — costs $300 of loot, blinds all cameras for 6s
- **P:** pause · **M:** mute
- Grab gems and paintings on the way. Three rooms, one getaway.

Play it: serve `game/` with any static server and open `index.html`, or
run `node serve.mjs` (development only) and open http://localhost:8080.

Built for the make.fun competition `best-heist-game-20261122-0559`.
